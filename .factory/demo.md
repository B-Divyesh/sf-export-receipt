# Demo

Open `/demo` or add `?demo=1` to load the Harbor Mail sample archive. It has two readable data files, one attachment, and dates from 2022-02-19 through 2025-01-08.

The persistent demo banner says **Demo — sample data, nothing is saved**. **Reset demo** reconstructs the sample from shipped bytes. **Start for real** drops the in-memory sample and opens the real local file picker. Demo data never uses localStorage, IndexedDB, or a network request.
